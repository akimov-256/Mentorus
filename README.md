An AI-powered study assistant built with Qt6 and QML.

## Installation

### Prerequisites

- Qt 6.10 or higher
- C++17 compatible compiler
- CMake (bundled with most Qt installations)
- MinGW (Windows) or GCC (Linux)
- A Groq API key (for AI-powered chat, quizzes, and lesson explanations)

### Building from Source

```bash
# Clone the repository
git clone https://github.com/akimov-256/Mentorus.git
cd Mentorus

# Configure with CMake
cmake -B build -S .

# Build the project
# Windows (MinGW):
cmake --build build --config Release

# Linux:
cmake --build build --config Release
```

### Pre-built Binaries

Download the latest release for your platform from the [Releases page](https://github.com/akimov-256/Mentorus/releases).
